# Qur'an text — source and license

The Qur'an text in this package comes from the **[Tanzil Project](https://tanzil.net)**:

| File | Tanzil text | Version |
|---|---|---|
| `sources/quran-uthmani.xml` | Uthmani (with pause marks, sajdah, rub el hizb, tatweel) | 1.1 |
| `sources/quran-simple-clean.xml` | Simple Clean (plain spelling, no diacritics) | 1.1 |
| `sources/quran-data.xml` | Metadata (surahs, juz, pages, sajdahs) | 1.0 |

License: **Creative Commons Attribution 3.0**, with Tanzil's terms of use:

- The text may be copied and distributed **verbatim**. **Changing it is not allowed.**
- It can be used in any website or application, provided its source (Tanzil Project) is
  clearly indicated and a link is made to tanzil.net so users can track changes.
- The copyright notice must be included in all verbatim copies and reproduced in all files
  derived from or containing a substantial portion of the text.

How this package complies:

- `sources/` holds the unmodified downloads, including their copyright blocks.
- `data/` is generated by `scripts/build-data.mjs`. It only reorganises the text into
  per-surah JSON files. Each ayah string is copied character-for-character, and every
  file embeds the full Tanzil copyright blocks in its `notice` field.
- `src/index.spec.ts` checks that all 6,236 ayahs in `data/` are identical to `sources/`.
- The app shows the attribution with a link to tanzil.net.

To update: download new versions from https://tanzil.net/download/ into `sources/`, then run
`npm run generate -w @repo/quran-data` and `npm test -w @repo/quran-data`.
